# 词笺 · Lemnota

*Worth noting.*

A personal vocabulary journal, built around words, notes, and the connections between them.

**[Open Lemnota](https://evelyn-y-chen.github.io/gre-quick-recall/)** · **[中文版](README.md)** · **[Suggestions & issues](https://github.com/evelyn-y-chen/gre-quick-recall/issues)**

No registration is needed. Choose a few words, try to recall them, and use red, yellow, or green to record how familiar they feel today. When you want to check your recall more closely, start a test.

## Why I made Lemnota

I wanted a vocabulary tool that felt easier to begin using.

Many study apps start with a test. For me, the fear of getting things wrong could turn into anxiety before I had even begun, and sometimes I would avoid opening the app altogether. Lemnota puts a simple red–yellow–green review mode first: record what you remember today, start whenever you feel ready, and stop whenever you need to. Tests are still available when you want to check your memory.

I also wanted somewhere to keep my own notes. Few vocabulary apps I had tried let me freely record and revise a memory method for each word. A teacher's explanation, a connection that suddenly makes sense, or a distinction between confusing words can disappear if I do not write it down. I wanted a small space beside each word where those thoughts could stay—and change as I learned.

This began as something for myself. I am sharing it free of charge in the hope that it may help others too. Suggestions are welcome through [GitHub Issues](https://github.com/evelyn-y-chen/gre-quick-recall/issues); I will improve what I can, gradually. The project is still evolving. You do not need to use every feature—start with the approach that works for you.

## Behind the Name · 名字的由来

### 词笺 · Between Words

*Jian* (笺) means both a slip of paper and a written annotation. The name also echoes 词间 (“between words”), reflecting the connections we discover through language.

### Lemnota · Words & Notes

From *lemma*, a dictionary headword, and *nota*, Latin for a mark or note.

*A word, and the thoughts we leave beside it.*

### Worth noting.

To note is both to notice and to write something down.

*In the margins, something of your own.*

在词与词之间，留下自己的注解。

## Getting started

1. Open the website and choose a palette. An optional nickname will appear in your backup filename.
2. Select **开始刷词** (Start reviewing), choose a list and a small range, then review in order or shuffle.
3. Recall the meaning before revealing it. Mark your confidence with red, yellow, or green, and edit a word's note when useful.
4. Use **开始测试** (Start test) when you want to check your recall.
5. Submit edits with their Save buttons. **已存到这台设备** (Saved on this device) confirms they have reached browser storage. Export a learning note periodically.

The **使用指南** (Guide) is always available at the top. Select the **词笺 · Lemnota** wordmark to return to the start screen. **关于词笺** (About Lemnota) explains the name and the idea behind the project. The interface is currently in Chinese; this guide includes its key labels.

## Red, yellow, green: record how it feels today

| Mark | Meaning | A useful next step |
| --- | --- | --- |
| Red — unfamiliar / not recalled | You cannot recall it yet | Bring it back for focused review |
| Yellow — uncertain / partly recalled | Familiar, but not clear | Review it and note the confusing part |
| Green — familiar / clear | You can actively recall it | Move on and check it again later |

These are self-assessments for this review. You can change them at any time, and you do not have to get everything right. Filter review screens by familiarity; some allow several colors at once. Mark-saving controls save to your own current workspace.

**The vocabulary notebook uses the same system.** Review your collection in compact rows, reveal definitions and notes, and rate each word. Keyboard navigation scrolls the active notebook word toward the middle of the screen.

## Your vocabulary notebook

- **Record context first.** Create a collection with a source and date to find the original article, question, or lesson later.
- **Use one search box.** Search all modules, filter by list, or enter and edit a new word yourself.
- **Choose several definitions.** Select several sources for the same word. Within a collection, they combine under one entry with their source information retained.
- **Set your source order.** Move sources up or down under **词库来源优先顺序**; results follow your preference.
- **Use bilingual dictionary meanings.** If there is no list match, the dictionary/manual area opens using the word already typed. Choose ECDICT meanings to insert, then revise them.
- **Switch editing and review modes.** Edit words, definitions, and sources; review in compact rows with hidden meanings and notes until revealed. Subdued source labels keep definitions clear.
- **Use marks and shortcuts.** Rate words and navigate with arrows, Enter, Space, and 1 / 2 / 3. An on-screen undo restores an accidentally removed word.

Save notebook edits with **保存到当前工作区** (Save to current workspace). Shared memory edits use **保存全部笔记** (Save all notes).

## One word, one personal memory note

Default memory methods come from edited GLEE, A+, and BB material, including deduplication and shortening. They are not verbatim course transcripts. Private edits saved on the author's personal website have not been imported as public defaults.

Where memory notes are supported, the same word uses one personal note across modules. Edit it wherever you encounter it; after saving, the update appears elsewhere too. Edit several words, then use **保存全部笔记 / 保存全部记忆方法** (Save all notes / memory methods) to save together.

“Shared” means **between your own modules**, not published to other learners. Separate browser profiles keep independent edits; one person's changes do not rewrite the default lists for everyone.

## Tests, when you want them

### Two-direction definition tests

General vocabulary, A+, and BB have test buttons near the top. Choose a List range, ordered or shuffled questions, and **English → Chinese** or **Chinese → English**. A+ and BB can also add a **definition + one synonym out of six** step.

Choose **不确定** (Not sure) whenever you do not know. Feedback shows option meanings, correct answers, and memory notes in place. A first fully correct attempt completes the word. After an error, it returns after five intervening questions and needs two consecutive fully correct attempts; another error resets the streak. With fewer questions remaining, it returns sooner. Save and return, then continue the previous test later.

### A+ two-step equivalents and spaced review

The original full A+ test is under **速刷与笔记 / 开始测试** (Review & notes / Start test):

1. Choose the core word's definition.
2. Select synonyms from six words in **single-answer** or **select-all-that-apply** mode.
3. See every option meaning and missed/incorrect selections in place, with the memory note shown directly.
4. Incorrect words return after five questions. Missed and incorrectly selected options carry into the next practice. A first fully correct two-step attempt completes the word. After an error, two consecutive fully correct attempts are needed; another error resets the streak.

Distractors come from the full list and are filtered using known synonym relationships and exclusion rules. Automatically generated practice may still contain debatable semantic distinctions; please report the core word and options if you find one.

Long-term A+ review uses progressively longer intervals of **1, 2, 4, 7, 15, and 30 days**. An error resets the word's schedule and brings it back the next day. This schedule belongs to the original A+ test; other two-direction tests currently offer within-session error review only.

## Keyboard shortcuts

| Key | Common action |
| --- | --- |
| ↑ / ←, ↓ / → | Previous / next word or group |
| Space | Read the active word; BB reads the first word in a group |
| Enter | Reveal or hide; confirm, submit, or continue in tests |
| 1 / 2 / 3 | Red / yellow / green |

Follow the current module's on-screen hints. Typing in inputs or note editors does not trigger review shortcuts. Pronunciation uses browser speech synthesis and the device's available voices.

## Saving, backups, and moving devices

### Save without signing in

Saved notes, familiarity marks, tests/review history, source order, nickname, and palette are written automatically to the current browser's IndexedDB. Return with the **same website address and browser profile** to continue. Submit editor changes first, then check for **已存到这台设备** (Saved on this device).

Devices and browser profiles have separate data; people sharing one profile share its workspace. Private browsing, clearing site data, or browser cleanup can remove local records. Revision checks help prevent stale tabs from overwriting new records, but editing in one tab is recommended.

### Take a learning note with you

1. Save edits and select **带走便笺 / 导出我的便笺** (Export my learning note).
2. Download a JSON file named with your nickname and local date/time, such as `词笺_小词_便笺_2026-10-14_153538.json`. Without a nickname, it uses 我的 (“mine”).
3. Open Lemnota on the new device, choose **读取便笺 / 我有一张便笺** (Import a learning note), select the file, and confirm.
4. Saved records and palette return, followed by a brief confetti message.

**Import replaces destination records; it does not merge them. Export existing destination records first if you want to keep them.** Legacy GRE JSON backups are supported. Slips are ordinary, unencrypted files; keep them private. Unsaved drafts are not guaranteed to be restored.

Guests do not need an email or password. A learning note carries its data independently of an account.

## Account sync

**GitHub sign-in is enabled**, with account workspace synchronization implemented. Google sign-in is on hold. Email/password sign-in is retained; email registration and email links remain unavailable. GitHub sign-in does not require Gmail SMTP. Actual cross-device saving still needs verification; see [Project status](PROGRESS.md).

Notes, familiarity marks, notebooks, tests, source preferences, and palettes save to the signed-in account. Guest data and per-account device caches stay separate. A new account can explicitly import guest records; existing cloud progress is read first. Concurrent conflicts retain a local backup rather than silently replacing cloud records. Signing out restores the guest workspace. Offline account edits stay in that account's local cache and can be retried when connected.

See [authentication setup](AUTH_SETUP.md) for maintenance. After signing in with GitHub, check for the account-save confirmation and keep an exported learning note as a backup.

## Appearance and web app

Choose **Snowy Sunset, Lakeside Iris, Twilight Snow, or Apple Paper**. Each swatch represents background, cards, primary actions, and selection/highlight, respectively. The palette travels with your slip; red–yellow–green meanings stay consistent.

Use the website on computers, phones, or iPads. Supported browsers can **Add to Home Screen / Install app** for a standalone web-app experience. There is no app-store release yet; full offline use is not guaranteed.

## Local development and publishing

Requires Node.js 24:

```sh
npm ci
npm run dev
npm test
npm run build
```

GitHub Pages uses the `/gre-quick-recall/` subpath:

```sh
BASE_PATH=/gre-quick-recall/ npm run build
```

`.github/workflows/pages.yml` builds, tests, and deploys `dist/` on a push to `main` or a manual run. The current workspace uses browser-local storage. Supabase provides account cloud storage; the configuration status is described above.

Source information remains with vocabulary and dictionary material. See the [dictionary license](dictionary-data/LICENSE.txt) for ECDICT. Free sharing does not change third-party rights; this project does not grant a separate open-source license for third-party word lists.

## Basic usage analytics

Learning requires agreement to basic usage analytics; previous consent does not accept the revised notice. Records include dates, features, counts and technical identifiers, not note or backup contents. Aggregates support improvements and project, portfolio or research presentations; data is not sold or used for advertising or other commercial purposes. Withdrawal exits learning but preserves export and workspace-clearing controls. Usage records are retained long-term for project analysis.

Only the author's server-verified GitHub identity can open the dashboard. It shows real account totals, daily/monthly consenting visitors, review actions, note saves, completed practices, learning-note exports, trends, feature use and 7-day retention. Guest-to-account transitions and changing browsers can duplicate visitor counts. Review actions are reveal/rating interactions, not a count of unique words. There are no demonstration statistics.

The personal edition can export a sharing-edition learning note from its library-and-records section. The new Lemnota icon is used for installation and browser icons. An existing home-screen shortcut may need to be added again to update its icon; keep a backup first.
