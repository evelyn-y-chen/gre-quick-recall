# 词笺 · Lemnota

*Worth noting. · 值得记下*

一个围绕单词、笔记与词语之间的联系而设计的个人词汇学习小白板。

**[打开词笺](https://evelyn-y-chen.github.io/gre-quick-recall/)** · **[English README](README.en.md)** · **[建议与问题](https://github.com/evelyn-y-chen/gre-quick-recall/issues)**

不用注册，也不用先接受一场考试。选几组词，想一下，再用红黄绿记下这一次的掌握情况。想检验记忆时，也可以开始测试。

## 为什么做词笺

我做这个网页，最初是想给自己一个更容易开始背词的地方。

许多背词软件一打开就进入测试。对我来说，还没开始，便会因为担心答错而焦虑、畏惧，最后干脆不打开。于是，词笺把红绿灯自测放在前面：今天记得多少，就诚实地标多少；随时可以开始，也随时可以停下。测试仍然保留，在想确认自己记住了多少的时候使用。

另一个原因是笔记。我很少遇到能让我自由记录、修改每个单词记忆方法的词汇 App。课堂上的讲法、突然想到的联想、容易混淆的地方，如果没有及时写下来，之后就会忘记。我希望每个词旁边，都有一个能留下自己的想法、也能继续改写的位置。

这个小工具从自己的需要出发，免费、公益分享，也希望能帮到其他正在学习的人。如果你有建议，欢迎[告诉我](https://github.com/evelyn-y-chen/gre-quick-recall/issues)。能做到的，我会逐步改进。它还在完善中，不必一次用完所有功能，先从适合自己的方式开始就好。

## 名字的由来 · Behind the Name

### 词笺 · Between Words

「笺」，既是一纸便笺，也是字句间的注解。「词笺」与「词间」同音，寓意在记录词语的同时，发现它们之间的联系。

### Lemnota · Words & Notes

由 *lemma*（词目）与拉丁语 *nota*（记号、笔记）组合而成。

一个词目，几笔注记。

### Worth noting. · 值得记下

既是「值得注意」，也是「值得记录」。

*In the margins, something of your own.*

在词与词之间，留下自己的注解。

## 第一次使用

1. 先选保存方式：点击「登录 / 注册」创建用户名与密码（无需邮箱），或使用已开放的 GitHub 登录同步账号；或选择「直接使用 · 便笺模式」，不注册也能在浏览器保存，导出便笺后换设备读取。再选配色与可选昵称，昵称会写进便笺文件名。
2. 点击 **开始刷词**，选择词库和一个小范围，按原顺序或乱序复习。
3. 先自己回忆，再揭晓释义。用红黄绿标记，也可以编辑单词旁的笔记。
4. 想检查记忆时，使用对应模块的 **开始测试**。
5. 编辑框有保存按钮时先保存；顶部显示 **已存到这台设备**，表示已提交的内容已写入浏览器。定期导出一张便笺留底。

顶部的 **使用指南** 随时可以打开；点击左上角 **词笺 · Lemnota** 可以回到开始界面。关于名字与创作初衷，也可以在网页的 **关于词笺** 中查看。

## 红绿灯自测：先记录，再慢慢熟悉

| 标记 | 含义 | 可以怎么用 |
| --- | --- | --- |
| 红 · 不认识 / 没想起 | 暂时想不起来 | 留到下一轮重点复习 |
| 黄 · 模糊 / 只想起部分 | 有印象，但不确定 | 再看一次，写下易混点 |
| 绿 · 熟悉 / 都清楚 | 能主动想起 | 继续往下，以后再回来确认 |

标记是这一次的自评，可以随时修改；没有要求每次都全对。速刷界面支持按掌握情况筛选，部分模块可以同时选多个颜色。标记的保存按钮会把记录保存到自己的当前工作区。

**生词本也有同样的红黄绿。** 收集完生词，切到复习模式，一行一行过词、揭晓释义与笔记、标记掌握程度。用方向键切换时，当前词会滚到屏幕中间，方便继续复习。

## 生词本：把遇到的词留下来

- **先记来源**：创建一次收集，写下文章、题目或课程来源与日期，以后能找到当时的语境。
- **一个搜索框添加生词**：从各模块搜索，按词库筛选；也可以直接输入新词，自行补充或编辑。
- **选择多份释义**：同一个词可以勾选多个来源的解释，在本次收集中合并到同一个词条下面；来源继续保留。
- **按偏好排序来源**：在 **词库来源优先顺序** 中上下调整，搜索结果按偏好排列。
- **查中英词典**：词库没有结果时，词典与补充区域自动展开，沿用已输入的词。可以从 ECDICT 中选择释义填入，之后再修改。
- **编辑与复习分开**：编辑模式修改单词、释义、来源；复习模式使用紧凑排列，先回忆，再揭晓释义与笔记。来源文字淡化，便于先看清释义。
- **红黄绿与键盘速刷**：给每个生词标记掌握程度，用方向键、Enter、Space 与 1 / 2 / 3 连续复习。误移除的词可通过页面上的撤销按钮找回。

编辑后请使用生词本的 **保存到当前工作区**；共享笔记的修改使用 **保存全部笔记**。

## 笔记：同一个词，共用一份记忆方法

默认记忆方法经过了去重与简化，不是逐字课程实录。作者个人网站中保存的私人修改未被用作公共默认笔记。

### 学习视频与笔记来源

- **配合视频学习**：A+ 与 GLEE必备1500词在相关网站或 B 站上有部分公开的带背／带练视频。可以按课程或词表名称，加上「带背」「带练」等关键词自行搜索。
- **视频笔记**：默认笔记大部分由作者根据 A+、GLEE 等公开视频整理，并做过去重与简化，便于复习和补充自己的理解。
- **BB 记忆方法**：来自上、中、下三份 PDF 原资料，不属于视频笔记。
- **其他词表**：全能词速刷与等价词速刷的词表来自青山学堂；填空高频3000词根据网络资源整理。
- **AI 整理内容**：GLEE 从 **List 22（含）** 开始的后续默认笔记由 AI 整理。整理时，老师的视频尚未更新到这一部分，因此这些笔记并非来自对应的视频讲解。

在提供记忆方法的模块中，同一个词共用你自己的那一份笔记。你可以就地编辑，保存后，其他模块遇到这个词时也会显示修改后的内容。可以先修改多个词，再用 **保存全部笔记 / 保存全部记忆方法** 一次保存。

这里的「共享」指**自己各模块之间共用**，不是把笔记公开给其他人。独立浏览器空间保存各自的修改，默认词库不会因某个人的编辑而被改写。

## 测试：需要时，再检验一下

### 双向释义测试

全能词、A+ 与 BB 顶部都有测试入口。选择 List 范围、顺序 / 乱序，以及 **看英文选中文** 或 **看中文选英文**。A+ 与 BB 也可加上 **释义 + 六选一同义词**。

不知道时可以选 **不确定**，不用靠猜。两步等价词测试第一步释义答错或不确定时，直接显示正确释义、对应等价词和记忆方法，跳过第二步选词；跳过的同义词不计为漏选，错题照常返场。作答后就地显示选项含义、正确答案与记忆笔记。首次全对的词直接完成；有过错误的词隔 5 题返场，连续两次全对才完成。中途再错，连续正确次数重新计算；剩余题目不足时提前返场。可保存并返回，之后继续上次测试。

### 双向测试的到期复习

全能词、A+ 与 BB 的双向测试各自记录长期复习计划。在测试设置页查看今天待复习、已纳入和逾期数量、下次日期，或点击 **查看到期词**。

- 点击 **开始到期复习**，复习该模块全部到期词，不受新词 List 范围限制。顺序、提示方向与题型沿用当前设置；开始会替换当前一轮，长期计划保留。
- 答对后的间隔依次为 **1、2、4、7、15、30 天**，之后每 30 天。同一天重复答对不会升级间隔。
- 答错或选择 **不确定**，该词从第二天重新开始；当天返场答对也不会跳过次日复习。
- 旧版已测词若没有可确定的日期，列入今天到期。三个模块独立记录，也不与 A+ 原有完整测试计划合并。

### A+ 两步等价词测试与滚动复习

在 A+ 的 **速刷与笔记 / 开始测试** 切换区，可以使用原有的完整测试：

1. 先选核心词释义。
2. 再从六个词中选同义词，题型可选 **单选** 或 **不定项**。
3. 原排版中显示全部选项的含义、漏选与误选反馈，记忆方法直接显示。
4. 出错词隔 5 题返场，漏选与误选的选项会保留到下一次练习。首次两步全对不重复；出过错后须连续两次两步全对，中途出错清零。

干扰词从全词表抽取，根据已有的同义关系与排除规则过滤。自动生成的练习仍可能遇到有争议的语义区分；如果发现问题，欢迎附上核心词与选项反馈。

A+ 完整测试保留原有长期计划，按 **1、2、4、7、15、30 天** 的间隔安排复习。出错会重置该词的曲线，第二天重新复习。该计划与全能词、A+、BB 双向测试的计划分别保存。

## 保存、备份与换设备

### 不登录，也能保存

已保存的笔记、红黄绿、测试与复习记录、来源排序、昵称和配色，会自动写入当前浏览器的 IndexedDB。下次用**相同网址、相同浏览器配置**打开，可以继续使用。编辑框有保存按钮时，请先提交编辑，再确认顶部显示 **已存到这台设备**。

各设备与各浏览器的数据独立；同一浏览器配置的使用者共用一份记录。清除网站数据、无痕浏览或浏览器清理可能导致本地记录丢失。多个标签页同时修改有版本检查，但建议只在一个标签页进行编辑。

### 用便笺带走进度

1. 保存当前编辑，点击 **带走便笺 / 导出我的便笺**。
2. 得到包含昵称与本地日期时间的 JSON 文件，例如 `词笺_小词_便笺_2026-10-14_153538.json`。未填昵称时使用「我的」。
3. 在新设备打开词笺，点击 **读取便笺 / 我有一张便笺**，选择文件并确认。
4. 恢复已保存的学习记录与配色；成功后会有短暂的彩带提示。

**导入会替换目标浏览器里的记录，不会合并。请先导出目标设备当前记录留底。** 旧版 GRE JSON 备份仍可读取。便笺是未加密的普通文件，请妥善保管；未保存的编辑草稿不保证恢复。

游客不需要邮箱或密码；便笺本身携带数据，不依赖账号。

## 账号与跨设备保存

**用户名与密码无需邮箱或发信服务**；GitHub 登录继续保留。已有 GitHub 用户可登录后选择「设置用户名登录」，为同一个账号添加用户名和密码，保留原进度。首次注册／绑定以及恢复后，请保存新生成的恢复码，忘记密码时凭码找回。密码与恢复码同时遗失且没有其他已绑定登录方式时，将无法找回账号。Google 后台尚未完成，邮箱注册未开放；实际跨设备保存的人工验证仍待完成，当前进度见 [项目进度](PROGRESS.md)。

同一个账号的笔记、红黄绿、生词本、测试进度、来源偏好和配色会保存到 Supabase；在其他设备登录读取。游客空间与每个账号的本机副本分别保存。新账号可以主动带入游客记录，已有云端记录会优先读取；同时修改导致冲突时会保留本机副本，供导出和核对，不直接覆盖云端。

退出后返回原游客空间。断网期间的修改会保留在该账号的本机副本；恢复网络后点击“保存到账号”。便笺备份仍然保留。

配置与维护步骤见 [账号登录配置](AUTH_SETUP.md)。使用 GitHub 登录后，确认顶部提示“已保存到账号”；仍建议保留一份便笺备份。

## 配色、手机与网页 App

可选 **雪林晚霞、湖畔鸢尾、暮色雪林、苹果古纸** 四套搭配。色卡依次表示背景、卡片、主按钮、选中与高亮。配色随便笺保存；红黄绿的含义始终一致。

电脑、手机与 iPad 都可通过浏览器访问。支持的浏览器可以用 **添加到主屏幕 / 安装应用** 作为网页 App 使用。目前没有上架应用商店，也不承诺完整离线可用。

## 本地运行与发布

需要 Node.js 24：

```sh
npm ci
npm run dev
npm test
npm run build
```

## 基本使用统计与管理员后台

进入学习前需要同意基本使用统计，旧版选择不会自动作为新说明的同意。记录日期、功能、操作次数及技术标识，不包含笔记正文或便笺内容；用于改进功能及项目介绍、作品集或研究的汇总展示，不出售数据或用于广告及其他商业用途。撤回后退出学习，仍可导出或清空当前学习空间。统计记录长期保留，用于项目分析。

作者用 GitHub 登录后可进入“统计后台”：累计注册账号、今日 / 本月活跃访客、词条复习次数、笔记保存次数、便笺导出次数、每日趋势、功能使用和 7 日留存。可选择近 7、30、90 天或「全部」，并显示所选范围活跃人数、复习次数与新增账号。后台仅向服务器验证的作者账号开放；普通用户无权查询统计表或后台汇总。所有数值来自真实数据，没有示例数字。统计只覆盖同意上报者；游客换浏览器或登录后可能重复计数，复习次数指揭晓或红黄绿操作次数，不是不同单词数量。留存需先累积足够天数。

个人网站“词库与记录”增加“导出分享版便笺”，可将已保存到个人云端的笔记、红黄绿、生词本与复习数据带入分享版。新版 App 图标已替换；旧主屏幕图标可能需重新添加后更新，请先保存便笺。


## 我的进步

首页与顶部「我的进步」展示练习过的词、自测熟悉词、已完成测试轮次，并按练习记录展示前三个板块的红绿灯进度条。单词去重、冲突取较不熟悉的状态；绿色是自评，不代表永久掌握。新测试轮次会累积保存，旧版仅计可识别的现存完成记录。数据随账号或便笺保存。
